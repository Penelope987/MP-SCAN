# MP SCAN Android nativo

## Offline-first (alpha04)

- O catálogo e as listas de capítulos são guardados no aparelho após a primeira sincronização.
- O botão `⇩` baixa todas as páginas do capítulo para o armazenamento privado do aplicativo.
- A Biblioteca lista os downloads, abre o leitor sem conexão e permite excluir cada capítulo.
- O leitor é nativo em Jetpack Compose; não abre o site dentro de WebView.
- Login, comentários e novas sincronizações continuam exigindo conexão.
